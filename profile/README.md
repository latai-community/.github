## What is LATAI?

We are a community of developers, AI enthusiasts, and researchers from Latin America. We learn AI by **building with AI** — creating real-world open-source projects where 90%+ of code, documentation, and testing is AI-generated, and humans review, refine, and ship.

**Free. Open-source. Hands-on.**

## Projects

| Project | Description | Stack |
|---------|-------------|-------|
| [**JPC**](https://github.com/latai-community/jpc) | File handling, text automation & utilities across platforms | Java, Python, CMD |
| [**DATIK**](https://github.com/latai-community/datik) | Minimalistic web tool for instant JSON visualization | Web |
| [**SMG**](https://github.com/latai-community/SMG-SmartMockGenerator) | Synthetic data generator for realistic POCs and prototyping | Java |
| [**Flaten**](https://github.com/latai-community/flaten) | Flatten an entire project into a single text file | Java |
| [**CalI**](https://github.com/latai-community/cali) | iCalendar generator from CSV or Excel | Python |
| [**PromptMgr**](https://github.com/latai-community/promptMgr) | Track prompts, models, versions, and evaluations | Python |
| [**Sidecar-Tagger**](https://github.com/latai-community/sidecar-tagger) | AI-powered file metadata generator with JSON sidecars | Python |
| [**fileKor**](https://github.com/latai-community/fileKor) | File organization utility (successor of Sidecar-Tagger) | Python |
| [**Hello Calculator**](https://github.com/latai-community/hello_calculator) | Calculator built to test AI-assisted development | TypeScript |
| [**W-ContactExporter**](https://github.com/latai-community/W-ContactExporter) | Export new contacts from a WhatsApp group | Utility |

**Got an idea?** We welcome proposals for new projects. Open an issue on any repo or drop it in Discord — if the community likes it, we build it together.

## How to Join

**3 steps to get started:**

1. **Join** our [WhatsApp Community](https://chat.whatsapp.com/LPgBVQcnDcRAk7Yi6WUWx7) — say hi in `#kernelAI`
2. **Connect** on [Discord](https://discord.gg/gH4XrVbbXM) — `GeneralDev` for dev talk, `Learning` for AI resources
3. **Contribute** — fork a repo, open an issue, or submit a PR

> **Not a developer? No problem.** You can still join, learn, and participate — share resources, suggest ideas, test projects, or just follow along. Not every contribution is code.
