# LatAI – Learning AI Through AI 🧠🤖

Welcome to **LatAI**, a free, open, and collaborative community supporting learning, experimentation, and open-source development in Artificial Intelligence.

We believe in **building real software with AI**, **learning together**, and **making AI knowledge accessible to Latin America and beyond**.

---

## 🌐 Who We Are

LatAI is a **technical community** where:

- **Contributors** collaborate on AI-related open-source projects
- **Learners** experiment with AI models and tools
- **Builders** create proof-of-concept projects and real applications
- **Educators** share knowledge through code, documentation, and tutorials

We operate with **no permission required**—you don't need to ask to start a project, suggest an idea, or contribute. You just participate.

Our community spans:
- 🌍 **Website**: [latai.org](https://latai.org/)
- 🐙 **GitHub Organization**: [github.com/latai-community](https://github.com/latai-community)
- 💬 **Discord**: Join voice channels for pair programming and discussions
- 📱 **WhatsApp**: Stay connected with the community

---

## 🚀 Getting Started

### New to LatAI?

1. **Check the Prerequisites** — Make sure you have:
   - Basic programming and Git knowledge
   - Experience using AI models (ChatGPT, Claude, etc.)
   - About 1 hour per week to participate
   - Understanding of Git basics: `clone`, `commit`, `push`, `pull requests`

2. **Introduce Yourself**
   - Join the WhatsApp community
   - Create an introduction in our [Saludos](https://github.com/latai-community/Saludos) repo
   - Tell us where you're from, why you're interested, and what you want to learn

3. **Explore Active Projects**
   - Start with the [Hello Calculator](https://github.com/latai-community) project to understand our workflow
   - Browse other repositories and pick something that interests you
   - Ask questions in Discord or WhatsApp—the community is here to help

4. **Do Pair Programming**
   - Don't work alone—find a partner to code, write prompts, or create documentation together
   - Use Discord voice channels to stay focused and connected

## 🛠️ Ways to Contribute

You don't need to write code to contribute. Here are many ways to add value:

- 🧠 **Improve AI prompts** — refine names, structure, and results
- 🧪 **Test AI models** — compare Claude, GPT-4, DeepSeek, and others
- 📚 **Write or translate documentation** — make projects easier to understand
- 🎨 **Generate useful resources** — images, videos, visualizations with AI
- 🧾 **Propose POC ideas** — proof-of-concept projects with AI
- 🛠️ **Start your own project** — no permission needed, just collaborate
- 🔍 **Review pull requests** — share feedback on others' work
- 🎓 **Create tutorials** — document what you've learned
- 📢 **Share resources** — find and share relevant AI news, events, and tools

## 📖 Community Values

We believe in:

✔️ **Open Collaboration** — Technical discussions and decisions are public and transparent  
✔️ **Technical Merit** — We prioritize code quality, security, and maintainability  
✔️ **Community Participation** — Your sustained contributions open doors to greater responsibilities  
✔️ **Human Accountability** — AI tools assist us, but humans remain responsible for reviewing and validating work  
✔️ **Vendor Neutrality** — We avoid unnecessary dependency on a single AI model, cloud provider, or commercial platform  
✔️ **Responsible AI** — We consider ethics, security, oversight, and real-world impact

---

## 🎯 Governance

LatAI operates with lightweight, transparent governance designed to **enable contribution rather than create bureaucracy**.

Key principles:
- **Routine technical decisions** are made through GitHub issues and pull requests
- **Material changes** (architecture, standards, governance) go through an RFC (Request for Comments) process
- **Decisions are made at the lowest appropriate level** while preserving quality and accountability
- **All processes are transparent** and recorded in GitHub artifacts

See our full [Governance Model](governance.md) for details on roles, decision-making, and how to propose changes.

## 🤖 AI-Assisted Development

LatAI encourages responsible use of AI tools in software engineering. You can use AI for:
- Coding and code review
- Documentation and tutorials
- Testing and architecture exploration
- Research and experimentation

**Important:** The human contributor remains responsible for:
- Understanding the submitted change
- Validating technical behavior
- Evaluating security implications
- Preventing disclosure of secrets or sensitive information
- Responding to review feedback

See our [Governance Model](governance.md) for detailed guidelines on AI-assisted contributions.
